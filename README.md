# Astra Phone Ultra — Titanium Flagship Landing Page

A flagship mobile phone landing page engineered with **Next.js 16**, **React 19**, and a bespoke **Vanilla CSS design system**.

## ✨ Flagship Design Highlights

- **Astra Phone Ultra Showcase**: Hero display featuring photorealistic commercial renders in Aerospace Grade-5 Titanium.
- **Interactive Finish Selector**: Switch dynamically between *Space Obsidian*, *Titanium Natural*, *Quantum Cyan*, and *Solar Amber* with responsive ambient backlights.
- **Interactive Horizon Island**: Simulated on-device pill expanding in real time for incoming VIP calls, lossless spatial audio waveforms, flight tracking, and Astra AI live voice translation.
- **200MP Quantum Periscope System**: Interactive focal length selector (0.5x, 1x, 2x, 5x, 10x Optical, and 100x Space Zoom) with detailed sensor specifications and macro imagery.
- **Astra N1 Neural Silicon (3nm)**: Custom processor showcase with interactive Ray-Tracing and on-device AI token generation benchmarks.
- **120W CryoCharge Simulator**: Interactive battery slider showing real-time charging minutes remaining, vapor chamber temperatures, and battery health telemetry.
- **Pre-Order Configurator**: Choose model (6.2" vs 6.8"), finish, and storage (256GB, 512GB, 1TB) with instant trade-in discount calculations and order confirmation modal.
- **Technical Specs Accordion**: Collapsible spec sheets for display, optics, battery, connectivity, and durability.
- **Sticky Purchase Bar**: Pops up on scroll with model thumb, price, and direct pre-order anchor.

## 🚀 Running Locally

```bash
# Run local development server
npm run dev

# Production build
npm run build

# Start production server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to view the live experience.
